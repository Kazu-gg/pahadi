# A Little Place Called Home ♡ · Kashish

A warm, personalized birthday website created with love for Kashish.

## ✨ Features
- 💌 **6 Interactive Letter Cards**: Beautiful unfolding letter envelopes with your heartfelt words
- 🎂 **Birthday Cake & Candle**: Tap the cake to blow out the candle flame
- ✨ **Pastel Confetti**: Confetti and floating hearts on wishes and letter reveals
- ♫ **Background Music**: Built-in soothing music-box chime with local MP3 support
- 📱 **Mobile Friendly**: Designed to look stunning on both phones and desktops
